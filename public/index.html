What this experiment does—and what it doesn’t measure

We deliberately truncate the available transcript by characters; this does not exhaust Gemma’s actual context window. The baseline gets the most recent transcript that fits. ContextCarry uses the same ceiling, reserving space for its compact handover and filling the rest with recent messages. System instructions and the question sit outside that ceiling and are identical. Actual provider token counts are shown after a call.

Later handovers receive only the previous active memory and new messages. The archive is used to check source links, not to recover forgotten facts. Source checks prove that a quote exists, not that a model’s interpretation is correct. Expected-answer matching is a text heuristic, not a semantic benchmark. Review the answers, include ties and failures, and repeat trials before claiming an improvement. The baseline is recent-history truncation, not another provider’s memory system.
