# Demo inputs and evaluation evidence

Keep a few small, shareable examples here so the demo and results can be reproduced.

For each case, record:

- Input and the task it represents.
- Expected behavior or a clear success criterion.
- Actual output from a real run.
- Model/configuration used and relevant measurements.
- Whether the case passed, failed, or was inconclusive.

Include a normal case and an unsupported or difficult case. Avoid committing private records, credentials, large model weights, or large videos; link to a hosted demo video instead.
